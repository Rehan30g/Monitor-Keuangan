Panduan MCP

Hubungkan aplikasi atau agen AI apa pun yang mendukung MCP (Model Context Protocol) ke akun UangKu-mu, supaya bisa membaca dan mencatat transaksi keuanganmu secara langsung. MCP adalah standar terbuka — dipakai oleh banyak aplikasi AI, bukan cuma satu produk tertentu. Ada dua cara menghubungkan, tergantung jenis aplikasinya.

1 Konektor web (mis. Claude.ai)

Paling mudah

Aplikasi yang punya menu "Tambah konektor" berbasis web biasanya cuma minta URL server — tanpa kolom token manual. Untuk ini, cukup:

  1. Tempel URL berikut di kolom "URL server MCP" / "Remote MCP server URL":
https://huzky.xyz/mcp
  1. Biarkan kolom OAuth Client ID/Secret kosong — server UangKu akan mendaftarkan aplikasi itu secara otomatis.
  2. Saat pertama kali dipakai, kamu akan diarahkan untuk login ke UangKu (kalau belum) lalu menyetujui izin akses. Setelah disetujui, koneksi langsung aktif — tidak perlu menyalin token apa pun.

Ini memakai OAuth 2.1 standar. Izin ini bisa dicabut kapan saja tanpa memengaruhi token akses milik aplikasi lain.

2 Token akses (Claude Desktop, Claude Code, dll)

Client berbasis file konfigurasi

Aplikasi yang dikonfigurasi lewat file (bukan lewat menu web) butuh token akses dan URL yang dimasukkan manual.

  1. Buka Pengaturan → Autentikasi → MCP di dashboard.
  2. Klik "Buat Token Baru", beri nama supaya gampang dikenali nanti (mis. "Laptop kerja" atau nama aplikasinya).
  3. Token akan ditampilkan satu kali saja — salin dan simpan sekarang. Token itu tidak bisa dilihat lagi setelah jendelanya ditutup (kalau lupa, tinggal buat token baru).

Token ini setara password untuk akun MCP-mu — jangan bagikan ke siapa pun. Bisa dicabut kapan saja dari halaman Pengaturan yang sama.

Header autentikasi yang dipakai:

Authorization: Bearer <token-kamu>

Contoh konfigurasi bergaya mcpServers di file JSON (pola yang dipakai banyak MCP client):

{
  "mcpServers": {
    "uangku": {
      "url": "https://huzky.xyz/mcp",
      "headers": {
        "Authorization": "Bearer <token-kamu>"
      }
    }
  }
}

Kalau aplikasimu tidak memakai format JSON seperti ini, cari kolom "Remote MCP Server URL" atau semacamnya, lalu isi URL di atas dan sertakan header Authorization dengan token-mu.

Kalau kamu memakai agen AI yang bisa membaca instruksi sendiri (mis. Claude Code, atau agen berbasis file konfigurasi lain), agen itu bisa memasang koneksi ini sendiri — lihat panduan agent (SKILL.md). Cukup minta agennya membaca file itu, lalu ia akan tahu apa yang perlu ditanyakan kepadamu.

3 Tools yang tersedia

list_transactions

Membaca daftar transaksi beserta ringkasan saldo, total pemasukan, dan total pengeluaran.

jenis (opsional): "masuk" atau "keluar" · cari (opsional): cari teks di keterangan

add_transaction

Mencatat satu transaksi baru.

jenis (wajib): "masuk" atau "keluar" · keterangan (wajib) · jumlah (wajib, angka Rupiah bulat positif)

delete_transaction

Menghapus satu transaksi berdasarkan ID (dapatkan ID lewat list_transactions dulu).

id (wajib)

4 Keamanan

  • Setiap token atau izin OAuth cuma bisa mengakses data akun pemiliknya sendiri.
  • Cabut token kapan saja dari Pengaturan — aplikasi yang memakainya langsung kehilangan akses.
  • Buat token terpisah untuk tiap aplikasi, supaya kalau satu perlu dicabut, yang lain tidak ikut terganggu.
